# Dark inspection interface

Approved in chat: charcoal backgrounds, layered panels, cyan accents, readable status colors, actionable dashboard queues, compact register filters and source shortcuts, focused asset tabs and persistent save action. Use existing HTML/CSS/JavaScript and only currently enabled fields. No database, import, export or scheduling changes.

## Approaches
Adapt the old visual language to the local workflows (selected); copying the old UI adds clutter and disabled scope; colors alone do not improve navigation.

## Validation
Verify empty and populated states, keyboard navigation, tabbed editing without losing changes, narrow screens, printing, and existing data tests.
