    Revert bulk correction

    This creates a new correction event. It is allowed only if every affected asset is unchanged since the bulk correction. Earlier verification will not be revived.

    Review duplicate assets

    Use this only after confirming both records describe the same equipment. Evidence is retained, and the retired ID will refer to the survivor.

    Review 19xx inspection dates

    Check the source and select only the dates that should be in the 2000s. These are current dates on active, applicable inspections; the original source is preserved. All dates start unselected.

    Review named dates

    Select dates to interpret in the 2000s, such as June -19 → 2019-06. Only missing months on active, applicable inspections are included. Original source values are preserved. All dates start unselected.

    Correct month-year dates

    This preview covers matching last and next dates on all active, applicable inspections across every register page and filter. Source values are retained, and populated months are not changed.

    Add January to year-only dates

    This preview includes matching last and next dates on all active, applicable inspections, across every register page and filter. January is your chosen default, not a recovered source month. Original source values remain stored.

    Correct selected assets

    Selection includes selected assets on other pages and outside current filters. Every affected value appears in the preview. Changes invalidate verification only for changed fields.

    Review selected records

    Search only changes what is shown; it does not change which selected records will be verified.

    Review and verify fields

    Select only fields you have checked against your evidence. Identity confirms the equipment even if it has no tag. Other fields keep their current verification state.
